## Names

The page may also hold the name of a student, whole or in part, written by hand or printed: on a name line, in a header, in a corner, anywhere. Say where each one is, so that it can be covered.

- `names`: a box for each place on the page where the name of a student is written or printed, in the same form and frame as a block's `box`: `[x0, y0, x1, y1]` as fractions of the full width and height of the first image. The box encloses every stroke of the name, with a little room to spare, and nothing else. A printed label such as "Name:" with no name beside it is not a name. A name is still reported as a block too. An empty list when the page holds no name.
